# Telecom X — Predicción de Cancelación de Clientes (Churn)

## Descripción del proyecto

Este proyecto tiene como objetivo desarrollar un modelo de *machine learning* para predecir la cancelación de clientes (*churn*) en la empresa Telecom X.

Se utilizan datos previamente limpiados y preparados en el desafío anterior para entrenar modelos de clasificación que permitan identificar clientes con mayor riesgo de cancelar el servicio.

La predicción del churn puede ayudar a la empresa a tomar decisiones estratégicas para mejorar la retención de clientes.

---

## Objetivos

- Analizar la distribución de la cancelación de clientes.
- Explorar la relación entre las variables del dataset y el churn.
- Entrenar modelos de clasificación para predecir la cancelación.
- Comparar el rendimiento de diferentes modelos de machine learning.
- Identificar variables importantes que influyen en la cancelación.

---

## Modelos utilizados

Se entrenaron dos modelos de clasificación:

- Regresión Logística  
- Árbol de Decisión  

Los modelos se evaluaron utilizando métricas como:

- Precision  
- Recall  
- F1-score  
- Matriz de confusión  

---

## Resultados

Los modelos permiten identificar patrones asociados a la cancelación de clientes.

Entre los factores que parecen influir en el churn se encuentran:

- Tipo de contrato  
- Gasto mensual  
- Tiempo de permanencia del cliente  

Este tipo de análisis puede ayudar a Telecom X a identificar clientes con mayor riesgo de cancelar el servicio y diseñar estrategias de retención.
